## About the Foundation

Trinetra Foundation is registered under Section 8 of the Companies Act, 2013, Ministry of Corporate Affairs, Government of India. We work directly at the grassroots level across Bihar to support children's education, provide food relief, organize free health camps, take care of cattle in gaushalas, plant trees, and assist families in need.

## Our 12 Core Focus Areas

1. **Food & Hunger Relief** — Daily community kitchens and dry ration support for destitute families.
2. **Education & Child Literacy** — Learning centers, school supply kits, and study assistance for rural kids.
3. **Healthcare & Medical Camps** — Free diagnostic checkups, doctor consultations, and basic medicine distribution.
4. **Animal Welfare & Gaushala** — Shelter, veterinary medical care, and daily green fodder for cattle and stray animals.
5. **Environment & Afforestation** — Tree plantation drives, clean water awareness, and green village initiatives.
6. **Women Empowerment** — Self-help groups (SHG), stitching, and handicraft skill development.
7. **Youth Livelihoods & Skilling** — Computer education, career guidance, and vocational training.
8. **Disaster Relief** — Emergency flood relief, dry rations, and clothing distribution.
9. **Human Rights & Legal Aid** — Citizen rights awareness and basic legal support for underprivileged villagers.
10. **Clean Water & Sanitation** — Tube-well maintenance and clean drinking water facilities.
11. **Care for the Elderly & Destitute** — Warm clothing, food kits, and healthcare support for senior citizens without support.
12. **Rural Art & Culture Preservation** — Supporting traditional local folk arts and cultural events.

## Getting Started

### 1. Prerequisites
- Node.js 18+ installed
- npm or pnpm

### 2. Setup
```bash
# Clone the repository
git clone https://github.com/mrsandeep2/TRINETRA_FOUNDATION.git
cd TRINETRA_FOUNDATION

# Install dependencies
npm install

# Setup environment variables
cp .env.example .env
```

### 3. Run Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```
